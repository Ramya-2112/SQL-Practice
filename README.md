## Topics Covered
- SELECT, WHERE, ORDER BY
- GROUP BY and HAVING
- JOINs
- Subqueries and CTEs
- Window functions
- T-SQL vs MySQL syntax differences

## Tools Used

- MySQL Workbench (MySQL)
